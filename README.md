# Vernonical website

Static, responsive homepage for Vernonical LLC.

## Files

- `index.html` contains the page structure and copy.
- `styles.css` contains the design system and responsive layouts.
- `script.js` contains the mobile navigation, scroll behavior and copyright year.

## Run locally

Open `index.html` in a browser. For a local web server, run `python3 -m http.server` in this folder and visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload all four files from this folder to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site currently uses `hello@vernonical.com` for contact links. Update that address in `index.html` if needed before publishing.
